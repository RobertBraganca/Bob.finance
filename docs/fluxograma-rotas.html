Passe o mouse sobre uma caixa para ver o caminho dela de ponta a ponta, o que mudou e em qual PR. Cada número mora numa tela só (decisions/0045): as caixas com contorno amarelo no passar do mouse são os domínios que o domínio escolhido lê; não há seta de volta. Os contornos tracejados são o que ainda não existe.

Entre a função e o banco (11/11): todo GET da insights passa primeiro pelo cache das leituras (api_cache): com a mesma versão dos dados e o mesmo dia, a resposta sai com uma consulta. Qualquer escrita, em qualquer função, sobe a versão por um trigger. As seis funções falam com o Postgres pelo pooler de transação com max_pipeline: 0 (PR #38): uma consulta nunca é encaixada numa conexão ocupada, que era a causa das travas.
